# ميعادي (Meyadi)

منصة حجز مواعيد للمحلات الصغيرة في مصر — مجانية بالكامل، عربي RTL، بدون تسجيل للعميل.

**الديمو:** https://meyadi.pages.dev/s/demo-salon/ (بيانات تجريبية)

## المزايا
- صفحة حجز عامة لكل محل برابط خاص، موبايل وويب، بدون تسجيل — برقم موبايل بس
- منع الحجز المزدوج على مستوى قاعدة البيانات (قيد فريد جزئي في SQLite/D1)
- "أي حد متاح": توزيع تلقائي على أول موظف فاضي
- لوحة صاحب المحل: جدول اليوم، حجز walk-in، حالة (تم/مجاش)، إيراد متوقع
- ملف عميل تلقائي مع عداد غيابات؛ العميل متكرر الغياب بيتحتاج تأكيد
- تذكيرات واتساب جاهزة بضغطة (روابط wa.me، صفر تكلفة API)
- قائمة انتظار: أول إلغاء بيقدم الميعاد لأول منتظر
- ولاء: كل حجز عاشر مجاني + كوبونات
- تقييمات بعد الزيارة بس (مربوطة بكود حجز)
- إحصائيات: أكتر خدمة، أوقات الذروة، نسبة الغياب، مصادر الحجز (?src=)
- تقرير أسبوعي بالعربي جاهز للإرسال
- مساعد حجز بالعامية المصرية (يفهم "حلاقة بكرة الساعة 6")
- QR للطباعة، PWA، استيراد عملاء CSV، صلاحيات موظفين بـ PIN

## التقنية
Cloudflare Pages (استضافة) + Pages Functions (API) + D1 (SQLite). بدون سيرفر وبدون تكلفة ضمن الحدود المجانية.

## التشغيل
```bash
npm test                 # اختبارات محرك المواعيد (node:test)
npx wrangler d1 create meyadi-db
# حط الـ database_id في wrangler.toml
npx wrangler d1 execute meyadi-db --remote --file=schema.sql
npx wrangler d1 execute meyadi-db --remote --file=seed.sql   # بيانات تجريبية
npx wrangler pages deploy public --project-name meyadi
```
