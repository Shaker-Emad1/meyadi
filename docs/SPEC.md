# مواصفات ميعادي

## الهدف
مشروع CV قوي: منصة SaaS متعددة المحلات لحجز المواعيد في مصر، مبنية بالكامل على الخطة المجانية من Cloudflare.

## مزايا التفوق
1. مجاني بالكامل (المنافسين باشتراك)
2. مساعد حجز بالعامية المصرية (محدش عنده)
3. إحصائيات وتقرير أسبوعي مجانا
4. أي نوع نشاط وأي عدد فروع/موظفين
5. إعداد 5 دقائق + PWA

## خطة التنفيذ (20 بند)
1. قاعدة بيانات متعددة المحلات + صفحة حجز تمنع التضارب
2. لوحة صاحب المحل (جدول، walk-in، إلغاء/نقل)
3. ملفات العملاء وسجل الغيابات
4. تأكيد وتذكير واتساب + رابط عميل للتغيير/الإلغاء
5. إحصائيات (خدمة/ذروة/غياب)
6. تتبع قنوات الحجز (?src=)
7. تجربة 2-3 محلات حقيقية (معلقة على شاكر)
8. قائمة انتظار ذكية
9. منع الغياب (تأكيد إجباري للمتكرر)
10. تقرير أسبوعي بالعربي
11. باقات/كوبونات/ولاء
12. تقييمات بعد الزيارة + بيانات المحل
13. QR للطباعة
14. PWA
15. استيراد عملاء
16. صلاحيات موظفين (PIN)
17. تصميم RTL موبايل + ويب
18. اختبارات + توثيق + README
19. ريبو GitHub عام
20. كارت في البورتفوليو

## منع الحجز المزدوج
قيد فريد جزئي:
`CREATE UNIQUE INDEX one_active_slot ON bookings(shop_id, staff_id, date, start_min) WHERE status IN ('confirmed','pending_confirm')`
أي إدراج متضارب يفشل ويرجع 409 — حتى تحت ضغط متزامن، لأن D1 بيعزل الكتابة على نسخة واحدة.

## حدود معروفة
- تذكير واتساب "التلقائي الرسمي" مدفوع (WhatsApp Business API) — الحل: روابط wa.me جاهزة بضغطة من اللوحة.
- Durable Objects مدفوعة — الاتساق بيتم بقيد D1 الفريد.
- حدود Cloudflare المجانية: 100 ألف طلب/يوم، D1: 5 مليون قراءة و100 ألف كتابة يوميا.
